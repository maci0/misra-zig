# Security policy

The local server, the published site, and the deploy path are mapped in
[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md). This file covers versions and
reporting only.

## Supported versions

Local tooling targets Zig 0.17.0 and Bun. Releases are Git tags; v0.2.0 and
later are also [GitHub releases](https://github.com/maci0/misra-zig/releases).
Fixes land on `main`; no backport policy is documented. The published
handbook is static and is deployed by hand from `main`.

## Reporting

There is no published disclosure contact or advisory process. A report has
no documented path to a fix.
